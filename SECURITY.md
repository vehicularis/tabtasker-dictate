# Security

## Supported versions

Security fixes go into the next release. Before you report something, check that it still happens in the
[latest release](https://github.com/vehicularis/tabtasker-dictate/releases/latest).

## Reporting a vulnerability

Please don't open a public issue. Tell us privately, in either of these ways:

- On GitHub: [report a vulnerability](https://github.com/vehicularis/tabtasker-dictate/security/advisories/new)
  from the Security tab.
- By email: info@vehicularis.com

Say what you found, how to make it happen, and the Dictate and macOS versions you saw it on (Dictate's
version is on its About page). We'll confirm we have your report, keep you posted while we fix it, and
credit you in the release notes if you'd like.

## What counts

Anything in this app or this repository, for example:

- speech, notes or text leaving the Mac without the person turning that on;
- Dictate reading or writing files outside what it's been given;
- another app or a web page getting Dictate to type, record or use its Accessibility or microphone access;
- a release that isn't what this repository builds.

A problem in a speech model or a third-party library belongs with its own project. If it affects Dictate,
tell us too.
